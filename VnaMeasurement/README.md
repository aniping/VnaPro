# VnaMeasurement

从不可变完整 IQ 帧提取原始 A/B 或同源参考的复数 S 参数，不拥有设备、标准采集或显示格式。`MeasurementProcessor::Calculate(frame, measurement, calibration)` 的第三项可省略，既有调用保持未校正结果。

处理顺序为原始波提取 → 稳定复数归一化 → 可选校准。接收波始终不校正；未覆盖的 S 参数保持原值。单端口用同点 D/S/R，双端口联合提取同一帧四参数并映射实际物理端口，支持 P2/P4 及反序端口。系数轴必须与原帧逐点一致，不能静默插值或重复套用。

`CalculateMany()` 按输入顺序返回测量，在本次调用内复用双端口或四端口联合结果，不保留跨帧缓存。四端口必须读取同一完整帧的全部 16 项原始比值后一次联合校正；缺源、坏参考或矩阵奇异不能只保留部分“成功”项。HTTP 每四条一批并立即投影，避免同时保存整个目录的完整点数组。非法模型/端口元数据明确拒绝，合法未覆盖参数仍返回原始比值；SCPI 严格批量 SDATA 另由服务拒绝缺失或覆盖不足的校准。

`TraceResult.calibrated` 标识实际使用的校准路径；无效样本、参考幅度、比值溢出和校准奇异均保留逐点错误。显示/协议只能投影这些结果，不另行复制校正公式。`calibration_processing` 覆盖校正处理位置、联合模型、源缺失及 RAW/覆盖边界；既有 `measurement_processor` 验证未校准合同。

服务版本、校准文件及采集流程见[校准接入与使用](../docs/校准接入与使用.md)。
