# 详细设计导航

> [返回文档入口](../README.md)

详细设计负责接口、字段、完整状态转移、并发协议和可执行验收。若这里与架构设计冲突，应先修正架构结论，不能在实现文档中另造一套产品模型。

每个专题都有一个导航页；导航页只帮你找文档，字段和状态机在分篇中。

## 先按问题进入

不需要先读完 17 篇。先选择当前问题，再进入对应专题：

| 当前问题 | 入口 |
| --- | --- |
| 公共数据含义、驱动隔离、硬件执行或采集组帧 | [D1 专题导航](./01-公共契约与硬件采集.md) |
| S 参数、校准数学、迹线处理或通道编译 | [D2 专题导航](./02-数值处理与通道编译.md) |
| 测量运行、触发、停止、完成或多通道调度 | [D3 专题导航](./03-运行时触发与调度.md) |
| 设置事务、对象删除、保存召回、校准工作流或结果持久化 | [D4 专题导航](./04-应用事务校准与存储.md) |
| 界面/SCPI/文件入口、共享资源或验收门 | [D5 专题导航](./05-适配器横切与验证.md) |

需要做端到端合同评审时，再使用文末的[完整相邻阅读顺序](#完整相邻阅读顺序)。
