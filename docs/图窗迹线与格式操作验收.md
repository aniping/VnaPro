# 图窗、迹线与格式操作

本次行为依据 [ZNB8 官方手册核对](research/ZNB8通道图窗与格式行为核对.md)。Web 原生操作以 ZNB 为目标，SCPI 继续采用 Keysight 已确认的标准命令子集，两者通过同一个 C++ 仪器状态执行。

## 操作与归属

| 操作 | 后端行为 |
| --- | --- |
| 连续扫描修改点数、频率或 IFBW | 完整帧边界提交，保留模式、触发源与运行编号；已有有限采集按 FIFO 先结束 |
| 初次启动 | YAML 的 `instrument.sweep.defaultSweepMode` 默认 CONT，可设 HOLD；页面刷新不重置仪器 |
| Format | 修改当前迹线格式与该格式默认尺度，不新增图窗 |
| All Diagrams / Maximized | 切换可见布局，保持全部图窗和成员；最大化当前图窗 |
| Overlay All / Split All | 单条显示命令合并全部显示迹线，或每迹线一窗；不修改测量定义 |
| Diagram 菜单 Add Trace / Add Trace + Diagram | 新默认 S21/dB 迹线；可在同一事务创建图窗 |
| Trace Config Add Trace | 复制活动测量与格式、尺度、标记；目标成员值语义独立 |
| Delete Trace / Delete Diagram | 原生操作保护最后迹线和最后图窗；删图窗连同其迹线定义删除，剩余图号连续重编号 |
| Add / Remove Marker | 每迹线十个普通编号，分配最小空闲编号；移除只关闭，保存位置及属性 |
| 选择活动迹线 | 选择所属图窗及主迹线，坐标网格跟随；曲线和活动标记置顶，不重排标题目录 |

活动曲线与标记置顶是用户明确要求的项目绘图规则；已核对手册确认活动标题高亮和坐标轴跟随，没有明确规定曲线的绘制层次。原生 Delete Diagram / Delete Trace 删除定义，SCPI 的窗口 OFF / 槽 DEL 仅解除显示关联并保留定义，不能因同名入口而混用副作用。

`Trc<n>` 使用最小空闲正整数，删除后可以复用；它是测量名称，不能当作图窗内显示槽号。每图窗独立保存 `traceSlots`，支持稀疏编号，删除中间成员不会改变其余槽号；FEED 同一名称到其他槽也保留指定槽身份。项目预算为 128 条迹线、128 个图窗，不宣称是商业仪器上限。

## 显示域与事务

`DisplayWorkspace` 保存逐迹线显示属性，`DiagramCollection` 管理显式图窗、主迹线和归属；`displayedNames` 是兼容协议的只读扁平投影。服务只负责控制权、FIFO、候选提交和采集屏障；HTTP/SCPI 将协议映射为意图。前端保留输入草稿、像素坐标及拖动预览，已应用状态由 C++ 保存，刷新和观察窗口读取同一份快照。

新增默认迹线、复制以及删除图窗使用目录事务，同时核对 `expectedRevision` 和 `expectedDisplayRevision`。图窗目标也在同一请求里传递，避免“先选窗、再新增”的竞争。失败保留原目录、图窗与版本；真正硬件故障进入 Fault，不能伪报回滚成功。

HTTP 使用 `POST /api/v1/measurement-actions/add`、`clone`、`delete-diagram`；新增/复制可带 `diagram` 和 `newDiagram`。显示请求 `action` 增加 `diagramSelect`、`overlay`、`split`，`layout` 可带目标图号。状态返回 `selectedDiagram` 和全部 `diagrams`，最大化时仍返回全部归属。

## 格式和读数

十三项常规格式：dB Mag、Phase、SWR、Unwr Phase、Lin Mag、Log Mag、Real、Imag、Delay、Delay Derivation、Polar、Smith、Inv Smith。旧 `realimag` 保留 API 兼容，不列入原生常规菜单。

Smith/Inv Smith/Polar 允许全部受支持复数测量。传输量和 RAW 的圆图使用原复数坐标，不能冒充负载阻抗；只有反射 S 参数返回归一化阻抗/导纳。Inv Smith 更换导纳网格，不给曲线取负。Log Mag 的响应是非负原幅值，显示范围保持正幅度，坐标取 log10；零幅值不绘制不存在的对数坐标，dB Mag 才用 `20 log10|z|`。

展开相位、群时延及其角频率导数在完整频轴上计算，再抽点传输；Marker 使用同一投影。Delay 为 `-dφ/dω`（s），Delay Derivation 为 `-d²φ/dω²`（量纲 s²）；当前使用有限差分，尚未实现厂商 Aperture Points 回归窗口。重复频率和无效区间不给出虚假的导数。Autoscale 只在命令执行时适配一次，后续扫描不修改已应用范围。

Polar 曲线仍使用 Re/Im；默认标记和拖动预览使用后端计算的幅值 / 相位。预览读取 markerValues、markerSecondaryValues 及各自状态，零幅值保留 0、相位未定义，不在前端计算 hypot 或 atan2。该原生默认映射基于官方示例，不能据此替换 PNA 标准查询的 Re,Im 返回。

## 验证

原问题先由真实 Vue SFC/Canvas 和 HTTP 请求复现：CONT 配置被拒绝、矩形活动迹线未置顶、菜单缺入口、S21 Smith 被禁用。回归覆盖完整帧配置屏障、显式归属、稳定稀疏局部槽、增删保护、混合格式、完整轴数学、显示 CAS 及跨协议观察。交叉审查的错误图窗 Unfeed 选择跳变和乱序图号重复重映射均已取得真实 C++ RED，再由专门回归验证修复。

2026-10-13：Windows 最新正式构建及 47 项 CTest 全部通过（48.20 秒），包含 Log Mag SCPI 刻度读回回归；WebUI 类型检查、生产构建及 149 项测试通过。实际 Chromium 验证 CONT 下 4000→4001→4000 点、运行编号始终为 3；S21 Smith 保留一个混合图窗，最大化保存原窗四条迹线及第二图窗；Split All 生成五个图窗，删除临时图窗连同 Trc7 定义与标记删除，重新添加复用 Trc7，删除独占迹线移除空窗。M2 保存 5 GHz，移除只隐藏 M2，重新添加恢复同编号与频率；新观察窗口只读显示两窗与 M1/M2。SCPI 观察连接核对相同 SMIT、窗目录/最大化、4001 点及 CONT。

CLion 的 `cmake-build-debug` 全量编译成功，完整 CTest 首轮 46/47；日志集成测试读取正在滚动的 `service.log` 时出现一次 Windows `PermissionError`，单独重跑该项通过。该瞬时文件读取竞争保留在验收记录中，不将重跑描述为首轮全部通过。

同一脚本复测 4000 点、四条迹线：HTTP 帧读取中位数 48.56 ms、最大 99.08 ms；每迹线提供 2001 个绘图点，完整原始 4000 点仍用于后端数学及标记。浏览器未出现脚本 warning/error。实际叠加同一 S21 的四条曲线，选择 Trc1 显示绿色顶层，选择 Trc2 显示黄色顶层，标题顺序保留 Trc1/Trc2/Trc4/Trc5。

当前仍没有磁盘状态恢复、参考标记 R、Delta/Coupled 标记及完整四端口 S 矩阵；这些不以可点击占位控件冒充已实现能力。
