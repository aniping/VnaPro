# VnaPro 设计文档

VnaPro 用来把一份测量设置可靠地变成可查看、可保存、可追溯的网络分析结果。主线只有一条：**配置测量 → 设备执行 → 处理采样 → 形成测量结果**。

文档分为两级：架构设计先解释边界、职责和理由；详细设计再给出接口、字段、状态转移和验收用例。

术语不熟时先查[术语与命名约定](./术语与命名约定.md)。产品和架构正文使用中文主名称，精确英文标识符只在详细设计中保留。

> **评审状态：** 本套文档仍是候选设计；当前没有任何阶段或 ZNB/SNA 厂商兼容声明已经通过。完整冻结范围见下文“当前状态”。

1. [00 十分钟总览](./架构设计/00-十分钟读懂整体架构.md)与[01 总体分层](./架构设计/01-总体架构与分层.md)：先确认系统边界和依赖方向；

## 文档事实规则

- 架构设计说明“为什么这样分、谁对什么负责”。
- 详细设计说明“具体怎样实现、怎样验证”。
- 现状审计只说明当前代码与目标架构之间的差距。
- 依据文档只说明证据支持什么、不能证明什么；待采集证据必须明确标为待验证。
- 已删除的旧设计不再作为平行事实源；需要追溯时查看 Git 历史。
