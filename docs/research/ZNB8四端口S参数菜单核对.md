# ZNB8 四端口 S 参数菜单核对

核对日期：2026-10-13。GUI 依据为 [R&S ZNB User Manual v74 / FW V4.25](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1173_9163_01/ZNB_UserManual_en_74.pdf)，页码为 PDF / 正文页；本项目远控仍使用 Keysight 命令合同。

## 参数定义与端口能力

- ZNB 第 113–114、289 页定义 `Sij`：第一下标 i 是 DUT 输出 / 接收端口，第二下标 j 是输入 / 激励源端口。在无校准模型的原始比值中，源 j 激励时读取 `b_i / a_j`；不能交换成 `b_j / a_i`。
- 四个独立单端端口对应 16 个参数；两个独立单端端口对应 S11、S12、S21、S22 四个参数。对本项目无平衡端口、无外部矩阵的配置，合法条件为 `1 ≤ i,j ≤ portCount`。
- 第 1069 页明确 ZNB 有效编号取决于通道逻辑端口配置。第 288 页还允许按需激活实际存在、暂时标为 Unused 的物理端口；这不表示二端口仪器能创建不存在的 P3/P4。
- 当前项目的 `portCount=2/4` 表示对外可用仪器端口能力，菜单与 C++ 校验均应遵守它。底层驱动可能仍返回固定四路接收数据，这不能扩大已配置仪器能力；本次无需改变模拟驱动数据合同。

## All S-Params 是独立整组操作

- 第 290 页规定，单个 n 端口 DUT 的 All S-Params 创建 n² 个图窗，完整 S 参数各一迹线，并按 n×n 网格排列；多 DUT 配置按各 DUT 平方数相加。超过 100 个图窗时有警告取消流程。
- 该动作与“将活动迹线改成 S34”不同，不应把 All S-Params 绑定到单迹线更新接口。
- 第 1063 页的 R&S `DEFine:SGRoup` 创建整组 n² 迹线，但不等价于 GUI 的完整显示事务；重新定义组会删除原组。这是 R&S 专有命令证据，不是新增同名 Keysight 命令的授权。
- All S-Params 的复制 / 替换范围、命名、图窗分配和版本事务应单独设计；未实现整组动作时不能显示一个执行其他行为的可用按钮。

## Keysight 参数语法与越界拒绝

依据 [Keysight 官方 Calculate:Parameter 文档](https://helpfiles.keysight.com/csg/e5080b/Programming/GP-IB_Command_Finder/Calculate/Parameter.htm)：

- `CALCulate<cnum>:PARameter[:DEFine]:EXTended <Mname>,<param>` 创建测量但不显示；必须另行 FEED，不能因支持新 S 参数而改成自动显示。
- 单位数端口允许省略或使用下划线，因此 `S34` 与 `S3_4` 表达同一参数；两位数端口必须分隔，如 `S10_1`。这些是 Keysight 语法，不能套用 ZNB 等位数拼接规则。
- 官方 `MODify:EXTended` 修改该通道已选择的测量，参数合同与 DEFine:EXTended 相同；本项目当前命令子集尚未实现该指令，本次没有扩展修改命令。Web 原位更新仍维持已有选择和版本校验路径。
- 官方只允许仪器可用的 S 参数；不能仅因字符串符合 `Sij` 语法就在二端口配置接受 S33、S34 或 S44。

[Keysight 官方错误表](https://helpfiles.keysight.com/csg/e5080b/Support/PNA_Errors.htm) 的 Message 1882 / 1883 分别说明端口号超出允许范围、操作要求的端口数多于实际端口数，支持拒绝不存在端口。该页面没有把 DEFine:EXTended 的具体越界输入直接映射为 SCPI `-222`；若项目继续返回 `-222`，应标为项目既有错误合同，不称为实测原机固定编号。

## 项目验证边界

1. 四端口逐项验证全部 16 个参数，尤其非对角 S13/S31、S24/S42，核实 receiver/source 未颠倒。
2. 二端口只提供四个合法候选；HTTP、SCPI 和配置加载均不能绕过 C++ 端口范围校验。拒绝后保存目录、活动测量、显示和版本保持原状。
3. 验证 `S34` / `S3_4` 等价；语法合法但端口不可用与语法错误分别处理，不把越界参数静默夹紧到合法端口。
4. 页面刷新和观察窗口读取同一后端测量量；切换测量量继续遵守现有连续采集更新与显示事务，模拟驱动保持原样。
