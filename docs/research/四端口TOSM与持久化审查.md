## 发现与修复

| 问题 | 修复及验证 |
| --- | --- |
| 已选择 Single 且正在等待手动触发时，`INIT:CONT OFF` 命中幂等捷径，没有停止 | 专用动作强制经过真实 Stop 屏障；覆盖手动布防及门控在途完整帧，OPC 不提前完成 |

| 目录枚举在转换/分配异常时泄漏原生句柄，POSIX 混淆错误和 EOF | 两平台句柄使用 RAII；`readdir` 前清 errno，错误拒绝；公开同实例和跨实例并发合同 |
| Python HTTPError 和日志收集线程释放不完整 | HTTPError 用上下文关闭；进程退出后先 join 日志线程再关闭 stdout；模拟异常及实际进程验收通过 |
