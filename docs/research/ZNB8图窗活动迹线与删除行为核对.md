# ZNB8 图窗活动迹线与删除行为核对

核对日期：2026-10-13。文本依据为 [R&S ZNB User Manual v74 / FW V4.25](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1173_9163_01/ZNB_UserManual_en_74.pdf)，页码为 PDF / 正文页；视觉依据为用户提供的原机三图窗截图（视频 3:06）。

## 全局活动与图窗记忆

- 第 78 页明确：手动控制任一时刻只有一条全局活动迹线，与通道和迹线总数无关。
- 每个图窗记住上次活动迹线。重新激活之前未活动的图窗时，该图窗上次活动的迹线重新成为全局活动迹线。第 794 页说明点击图窗激活它及其上次活动迹线；点击迹线标题激活该迹线和所属图窗。
- 第 91 页明确活动迹线标题高亮，但正文没有给出非活动图窗的局部标题背景 RGB，也没有另立“多个全局活动迹线”的概念。
- 空图窗没有所属迹线，不能为了显示局部高亮而伪造一条迹线。远控的逐通道活动测量与上述 GUI 全局活动概念也不能混为一谈。

## 删除后的换色与选择

- 第 803 页明确工厂默认启用 `Trace Colors per Diagram`：每图从颜色 1 起按顺序循环；移除一条迹线时，同图中比它后创建的迹线会换色，跨图移动通常也会换色。这是默认行为，不是仅凭颜色即可认定的串选缺陷。
- 关闭上述 GUI 选项时，按全局创建顺序分配颜色，迹线保持原颜色编号；这是另一种原机配置，不能未经用户要求替换默认语义。
- 第 448–449 页规定 Delete Trace 删除活动迹线；该图唯一迹线被删时一并删除图窗；整个设置最后一条迹线禁止删除。第 795 页规定 Delete Diagram 删除图及其全部迹线，剩余图连续重编号，最后图窗禁止删除。
- 这些 GUI 条款未指定删除后选“下一条”“上一条”或“第一条”。不得将项目采用的确定性回退规则称为已经核验的原机算法。
- 第 1071 页要求 R&S 远控在通道活动迹线删除后重新选择迹线，这是远控条款，不能用于推定 GUI 后继规则，也不改变本项目的 Keysight SCPI 合同。

## 待办：迹线配色模式切换

记录日期：2026-10-13。状态：待办，用户要求暂不开发。当前项目保持每图独立循环配色，不提供模式切换入口。

- 原机入口：System → Display → Config → Define User Color… → General → Trace Colors per Diagram，依据手册第 801–803 页。
- 开启模式（默认）：每图独立按成员顺序循环配色，删除或移动迹线后允许重新分配颜色。
- 关闭模式：按全局创建顺序分配颜色，已有迹线在删除其他迹线或跨图移动时保持原颜色编号；不能用当前数组位置或可复用的 Trc 名称作为永久颜色身份。
- 后续实现约束：模式和需要保留的颜色分配由 C++ 共享显示域保存，前端只渲染；刷新及观察窗口读取同一状态，不自创或混入 R&S SCPI 命令。
- 验收范围：切换两种模式、删除不同位置的迹线、跨图移动、新增迹线及名称复用；标题、曲线、Marker 和信息字段颜色一致，存活迹线的格式、刻度和 Marker 设置保持。

## 对项目验收的直接要求

1. 全局活动迹线与所属图窗一致；每个非空图窗独立保留局部活动名称。删除无关迹线或其他图窗时，保留仍然存在的选择，不能用数组位置或颜色识别迹线。
2. 局部活动迹线被删除后，后端决定有效回退，前端只读取结果；活动与非活动图窗均不能指向已删除的名称。
3. 比较删除前后的 `selectedMeasurement`、`selectedDiagram`、各图 `primaryMeasurement` 和所属成员来验证选择；标题、曲线和 Marker 颜色统一跟随同一颜色来源。
4. 颜色数量可配置的正文依据为第 815 页，远控范围 1–100 见第 1566 页。第 813 页讨论透明信息字段，不能用来支持迹线色数或删除换色结论。
