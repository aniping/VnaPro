# 校准集适用性与插值证据

核对日期：2026-10-16。范围是 S 参数系统误差修正，包含校准集启用、扫频参数改变后的适用性及界面状态。功率计/接收机功率校准、迹线平滑、光标插值不是同一个功能，不能互相套用规则。本轮只读官方资料和仓库已有证据；未运行厂商软件、接触硬件或改变现有服务。

## 可落实的结论

是否需要插值应由**实际激励频点**决定，不能只比较起止频率或点数。当前每个频点都命中原校准点时，直接取对应误差系数；只有落在原校准点之间的点才需要估算。“范围缩小”和“点数改变”都不足以独立判断。R&S 的状态定义明确以每个点是否已有实测校准数据区分 Cal 与 Cal int，官方 ZVR 问答也只说改变范围/点数在多数情况下引入新频点。[ZNB v74 §4.5.4，p171](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1173_9163_01/ZNB_UserManual_en_74.pdf#page=171)、[ZVR FAQ，p2 Q1](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/dl_application/application_notes/1ez38/1ez38_3e.pdf#page=2)。

IFBW 改变不应一概判为校准无效，也没有证据保证 VnaPro 任意 IFBW 变化仍具相同精度。官方资料存在机型差异，甚至同套帮助不同章节的措辞差异；合理产品策略是保持可用、显示条件变化和噪声提示，不把它标为频率插值。范围外 S 参数修正应拒绝，不悄悄外推；范围外功率校准的外推功能不能作为例外移植到 TOSM。[Keysight：Error Correction and Interpolation，C Δ / No Corr / Interpolation](https://helpfiles.keysight.com/csg/NA520xA/S3_Cals/Error_Correction_and_Interpolation.htm)。

## 插值算法：证据够什么，不够什么

Keysight 的校准插值章节明确对象是**误差项**，并警告采样间隔、幅相突变、跨硬件频段会影响结果；相邻相位变化超过 180° 会使新相位估算失真。它没有在所核对章节公开通用的 Re/Im 线性、幅相阶次或延时补偿公式。[M9485A：Interpolation / Interpolation Accuracy](https://helpfiles.keysight.com/csg/m9485a/s3_cals/error_correction_and_interpolation.htm)。

R&S ZNB v74 词汇表 p1734 的 Interpolation 条目说通常采用相邻点线性插值，但没有明确复数误差项的坐标系及所有处理细节；因此该条目不能证明“对 Re 与 Im 各作线性”或“幅相线性与官方完全等价”。[ZNB v74 词汇表](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1173_9163_01/ZNB_UserManual_en_74.pdf#page=1734)。

独立数学检查：假设某跟踪项为恒幅纯延时响应，邻点相位为 −60° 与 +60°，真正中点为 1。Re/Im 直线中点为 0.5，即 −6.0206 dB；幅度与展开相位直线中点为 1。这说明算法选择有实际差异，**不是**证明所有误差项都应作幅相插值。幅度接近零时相位不稳定，高阶多项式也可能过冲；点间真实相位跨多周时，仅凭离散样本无法恢复真实延时。上述是数学反例/限制，不是厂商指标。

补充 primary 源码参考：核对 scikit-rf 固定提交 `edec903f2299e6b5aa5c772c528c5173b7af0487`，其 [`Network.interpolate`](https://github.com/scikit-rf/scikit-rf/blob/edec903f2299e6b5aa5c772c528c5173b7af0487/skrf/network.py#L2906) 默认 `coords='cart'`、未指定阶次时采用 linear；Cartesian 分支直接复数插值，Polar 分支对幅度及 `unwrap(angle)` 分别插值后重建。其 [`Calibration.coefs_ntwks`](https://github.com/scikit-rf/scikit-rf/blob/edec903f2299e6b5aa5c772c528c5173b7af0487/skrf/calibration/calibration.py#L572) 可把误差系数暴露为 Network；本文件未找到统一的 `Calibration.interpolate` 方法，因此不能把 Network 的默认值误写成所有校准对象自动应用的误差项策略。初始化时另有 ideal 标准网络轴对齐插值，也不是已求系数的通用激活算法。该开源实现说明两种坐标均有可复核实现，不代表任一商用仪器或 VnaPro 的实机精度认证。

本轮实现采用 **PolarLinearV1** 工程策略：非零端点的幅度线性、相位按相邻最短弧线性；任一端幅度精确为零时，相位无定义，回退 Re/Im 线性。幅相参数按源区间暂存，精确频点仍逐位复制。与固定 Snau 相比采用一阶而非最多八点 Lagrange，以避免高阶过冲和继承已发现的边界缺陷；与 scikit-rf polar 坐标具有实现参考关系，不能宣称厂商完全等效或同精度。派生后执行实际校正函数的完整系数验证，非有限幅度、零跟踪及病态结果拒绝应用。

必须以解析误差项及独立 DUT 数据验证。不能把“800 点增至 6700 点”宣传为提高校准精度：新系数来自估算，并未增加原始校准测量的信息。相邻真实相位变化超过 180°、未知硬件频段边界和未采样的相位绕转，无法从当前样本可靠恢复；所有插值持续提示精度风险，实机校准精度仍待验证。

## 本次产品规则（工程决策，不伪称厂商一致）

| 条件 | 修正及界面策略 | 依据 |
| --- | --- | --- |
| 相同轴，或当前轴是原轴的实际频点子集 | 直接取原系数，状态“Cal · 原频点”或“Cal · 子集”，不得标为插值。实际轴为整数 Hz，逐点精确比较，不引入 epsilon 容差吞掉真实频偏。 | E1/E4 + 数值判断策略 |
| 范围缩小但含新频点；范围内增/减点数且含新频点 | 命中点直接取值，新点插值；状态“Cal Int”，显示原/当前范围及直接/插值点数。范围缩小本身不等于无需插值。 | E1/E2/E4 |
| 保持点数但平移部分频点 | 同样逐点分类；不允许用“点数没变”判为直接应用。 | E1 的推论 |
| 任一点严格在校准区间外 | 不外推、不端点夹持、不混合部分修正与原始点。停止应用该校准，显示当前与原校准区间及重新校准建议；保存已选校准身份以便恢复。 | E1/E2/E4；“整扫一致”是产品决策 |
| IFBW 不同 | 允许修正，持久显示“条件变化”；分别提示变窄仍受原校准噪声限制、变宽会增加当前测量噪声。不要把它计为频率插值，也不承诺原精度。 | E2/E3/E4/E7；本机精度仍待实测 |
| 源功率不同、分段逐点功率不匹配 | 不在功率维度插值。精确频点须与其原功率相同；夹在两频点之间时，左右两点的原功率都必须与目标功率一致，不能跨功率边界插值。否则保守阻止，列出差异，提供恢复激励或重校。 | E7、本地思仪手册；逐点及双端相等门控是本产品保守决策 |
| 设备身份不同 | 拒绝应用；不能把别台仪器的系统误差项视为本机数据。身份只按已保存字段核对，不能捏造未采集的序列号/连接状态。 | 系统误差归属的工程决策；所查帮助未给跨设备通用放行合同 |
| 校准端口/类型不覆盖测量 | 标注具体未覆盖的 Sij，禁止显示为完整修正。是否支持部分迹线修正需与现有后端能力一致。 | E1/E5、本地手册错误 521 |
| 用户关闭、无选中集、损坏/空轴/不递增轴、插值后非有限/校正病态 | 分别显示“已关闭”“未选择”“不可用 + 具体原因”；损坏/数值错误不降格为可继续的提示。 | 状态设计 + 输入及数值完整性要求 |

推荐将“选择了哪个集”“用户修正开关”“当前适用性”“是否实际修正当前数据”分开建模。未应用、应用中、直接/子集、插值、条件改变、不可用应有可观察状态；`Cal Int` 与 IFBW 警告可以同时存在。启动池已在监听前完整装载时，前端不能虚构后台读取进度；用户切换时显示实际准备/请求状态，失败保留原有效状态。以上加载提示是产品设计，未在所查官方资料中找到可照搬的进度协议。

最小验证矩阵应覆盖：同轴、整数步长及非均匀精确子集、缩范围新频点、相同范围增点、混合命中/新点、两端越界、IFBW 两方向变化、功率/设备/端口不匹配、参数恢复后的状态恢复；插值须包含非平凡幅相、±180° 跨界、恒幅延时、接近零及数值失效。还应测 800/4000/6700 点配置准备成本与热测量，确保插值不会搬到采样热路径重复执行。
