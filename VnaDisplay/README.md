# 共享显示域

`VnaDisplay` 是仪器显示语义的唯一实现。它依赖 `VnaMeasurement` 和不可变采集帧，不依赖 `VnaService`、HTTP、SCPI 或任何 GUI。服务执行线程持有一个 `DisplayWorkspace`；该模块不创建线程、租约或采集状态机。

- `DisplayWorkspace` 保存活动测量、最多四个有序显示槽、布局和逐迹线格式、尺度、Smith 半径、可见性及 M1。`Snapshot()` 返回独立副本；`State()` 只供服务执行线程即时读取。
- `ArrangeDiagrams()` 从共享状态只读派生图窗描述。单图合并同类迹线，Smith 与矩形格式混合时分组；网格按有序槽逐条安排；最大化保留原图号。每组优先采用组内的全局选中项作为主迹线，否则采用组首。空显示集返回无主迹线的图窗 1。此描述不另存可写派生状态，也不扩展现有 SCPI 窗口 1 与迹线槽合同；各显示终端只需绘制返回的分组。
- `Reconcile()` 在测量目录提交时保留同名显示设置，移除失效项，并将不再适用的 Smith 恢复为此前的矩形格式。候选工作区可在提交采集计划前校验，防止显示版本耗尽造成部分提交。
- `ReconcileAxis()` 在物理配置候选中按真实刺激轴协调保存的标记频率和离散点，保证频段改变后保存坐标与读数一致；同轴 IFBW 或源需求变更保留合法 CW 原始下标。核心成功提交后调用 `BindAcquisitionRevision()` 更新已验证下标的隐藏采集版本，该绑定不改变可见设置或显示版本。
- `Apply()` 先构造候选、校验并计算，全部成功才递增独立显示版本。无变化操作不增版本，失败不修改状态；到达 `uint64` 上限时拒绝改变状态。控制权、预期显示版本与 FIFO 由调用者的服务执行器统一管理。
- `TraceProjection` 用完整复数数据执行显示格式转换及一次 Autoscale，区分有效值、无效点、负无穷、未定义相位和溢出。Smith 返回原始 Γ 实虚部，归一化阻抗不假定实际参考阻抗；字宽、字体、DPR 和像素坐标由显示终端处理。
- `MarkerResolver` 默认对真实频轴上的复数值进行线性插值。显式原始采样下标和步进改为离散点；CW 同频点仍保留采样下标。传输适配器可以抽点绘图，但标记独立读数必须来自完整原始数组。
- `ScaleCalculator` 将范围和每格尺度、参考值、参考位置规范化成同一个范围，Autoscale 只在命令执行时拟合一次。之后的采集帧只改变曲线，不更新已应用尺度。

`FrameContext` 使用一次读取的不可变帧、当前采集版本与运行编号。它也可以在同步命令期间借用已提交真实刺激轴；工作区不会保存该借用。Autoscale 和采样移动需要当前完整帧；物理版本检查不要求 `frameSeq` 等于浏览器旧序号，避免连续扫描时正常操作频繁失败。首帧前仍可按已提交刺激轴保存合法 Marker 频率，超出扫描范围原子拒绝，不由 HTTP 或 SCPI 各自钳制。纯显示配置无需获得采集数据。启用标记默认取真实频段中点；若没有可验证的刺激轴，先保留未定位置，首次投影以实际频段中点计算。

窗口刷新和另一观察窗口读取同一服务内存状态。此模块没有磁盘恢复合同；关闭并重新启动服务会采用初始显示设置。

单元验收分别运行 `display_workspace` 与 `trace_projection`，覆盖快照独立性、无变化版本、尺度部分修改、槽位与隐藏选择、纯派生图窗分组与原图号、目录及刺激轴协调、一次 Autoscale、首帧前合法频率与范围拒绝、采集版本校验、CW 与 10001 点原始标记、同轴硬件版本更新、复数插值及离散、异常值、Smith 与版本耗尽。
